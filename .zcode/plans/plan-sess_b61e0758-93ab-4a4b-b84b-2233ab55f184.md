# План: фикс аудио-бага после loadGame() + PR в upstream GeneralsX

## Первопричина (подтверждено диагностикой)
После `loadGame()` MiniAudio-группы (`m_soundGroup`, `m_sound3DGroup`, `m_speechGroup`, `m_musicGroup`) остаются в stop-состоянии. `MiniAudioManager::reset()` → `stopAllAudioImmediately()` чистит playing-списки, но не стартует группы заново. Новые звуки привязываются к остановленным группам → тишина. Открытие/закрытие ESC-меню вызывает `resumeAudio()` → `ma_sound_group_start()` → звук возвращается.

Из чек-листа по `docs/BUILD/MACOS.md` на твоём M3 Pro уже есть: Xcode 26.6, Homebrew 6.0.9, python3, ffmpeg, git, macOS 26.5.1, 81 GB свободно.

**Установить через `brew install`:**


## Этап 5 — Сам фикс (3 строки в `MiniAudioManager.cpp`)

Файл: `Core/GameEngineDevice/Source/MiniAudioDevice/MiniAudioManager.cpp`, метод `reset()` (строки 197-206).

**До:**
```cpp
void MiniAudioManager::reset()
{
    AudioManager::reset();
    stopAllAudioImmediately();
    removeAllAudioRequests();
    removeLevelSpecificAudioEventInfos();
}
```

**После:**
```cpp
void MiniAudioManager::reset()
{
    AudioManager::reset();
    stopAllAudioImmediately();
    // GeneralsX @bugfix coolswood 18/07/2026 Restart sound groups after reset so post-load audio is not silent.
    // stopAllAudioImmediately() releases individual sounds but does not restart ma_sound_group nodes stopped
    // by an earlier pauseAudio(). After loadGame() the groups stayed stopped, so every newly created sound
    // attached to them was silently dropped by processPlayingList() — opening/closing the ESC menu "fixed" it
    // because pauseGameSound(FALSE) -> resumeAudio() -> ma_sound_group_start(). Restart them here.
    resumeAudio(AudioAffect_All);
    removeAllAudioRequests();
    removeLevelSpecificAudioEventInfos();
}
```

Безопасность: `resumeAudio` вызывает `ma_sound_group_start` на 4 группах — это idempotentная операция (повторный старт уже стартованной группы безвреден). Вызывается при каждом reset, включая деструктор GameEngine, но там это no-op.

## Этап 7 — Коммит и PR

Коммит по конвенции проекта (Conventional Commits + scope `audio-miniaudio`):
```
fix(audio-miniaudio): restart sound groups in reset() to fix silent audio after loadGame

MiniAudioManager::reset() released individual playing sounds but did not restart
the ma_sound_group nodes that an earlier pauseAudio() had stopped. After loadGame(),
the groups stayed stopped, so every newly created sound attached to them was silently
dropped by processPlayingList() — and opening/closing the ESC menu "fixed" it because
pauseGameSound(FALSE) -> resumeAudio() -> ma_sound_group_start(). Restart the groups
in reset() to restore audio immediately after a save load.
```
