## Повторение: определенность в чанках

1. «Спасибо за помощь.» → *Tack för hjälpen.* ✅
2. «Спасибо за предложение, но квартира слишком дорогая для меня.» →
   *Tack för förslagen men lägenheten är för dyr för mig* ⚠️
   * Правка: *Tack för förslaget, men lägenheten är för dyr för mig.*
   * Правило: *förslaget* = одно конкретное предложение; *förslagen* = предложения во множественном числе.
3. «Я могу прийти в среду после работы.» →
   *Jag kan komma på onsdag efter jobbet* ✅

Контраст:
* *Tack för förslaget* ✅
* *Tack för förslagen* ✅
* *Tack för hjälpen* ✅

## Fritid & intressen: базовые действия

1. «В свободное время я люблю слушать музыку.» →
   *På fritiden gillar jag lyssnar på musik* ⚠️
   * Правка: *På fritiden gillar jag att lyssna på musik.*
   * Правило: *gillar att + infinitiv*.

2. «В субботу я хочу встретиться с другом.» →
   *På lördag vill jag träffas min vän* ⚠️
   * Правка: *På lördag vill jag träffa min vän.*
   * Правило: *träffa någon* = встретиться с кем-то; *träffas* = встретиться друг с другом.

3. «Мы можем пойти в парк после работы.» →
   *Vi kan komma till parken efter jobbet* ⚠️
   * Правка: *Vi kan gå till parken efter jobbet.*
   * Правило: *gå* = пойти; *komma* = прийти/прибыть.

Повтор:
* *På fritiden gillar jag att laga mat.* ✅
* *På lördag vill jag träffa min vän i parken.* ✅
* *Vi kan gå till parken efter jobbet.* ✅

## Мини-цепочка

Задача: «В свободное время я люблю готовить еду. В субботу я хочу встретиться с другом в парке. После этого мы можем пойти в кафе.»

Ответ:
* *På fritiden gillar jag att laga mat. På lördag vill jag träffa min vän i parken. Efter det kan vi gå till kaffet* ⚠️

Правка:
* *På fritiden gillar jag att laga mat. På lördag vill jag träffa min vän i parken. Efter det kan vi gå till ett kafe.*

Комментарий:
* *kaffe* = кофе, напиток.
* *kafe* = кафе, место. Студент пишет без акцента, это принято как нормальный ввод.
* Очень хорошо сработал V2: *Efter det kan vi...*

Повтор:
* *Vi kan gå på kafe.* ✅
* *Vi kan dricka kaffe.* ✅
* *Jag vill träffa min vän i en annan kafe* ⚠️
  * Правка: *Jag vill träffa min vän på ett annat kafe.*
  * Правило: *ett kafe* → *ett annat kafe*; место встречи: *på ett kafe*.

Контраст:
* *en annan lägenhet* ✅
* *ett annat kafe* ✅
* *ett annat hus* ✅
* *en annan vän* ✅

## YKI-применение: предложить другое место

Задача: «Спасибо за предложение. Я не хочу встречаться в парке, потому что сегодня холодно. Можем встретиться в кафе?»

Ответ:
* *Tack för förstaget. Jag vill inte träffas i parken eftersom det är kallt idag. Kan vi träffas på kafe?* ⚠️

Правка:
* *Tack för förslaget. Jag vill inte träffas i parken eftersom det är kallt idag. Kan vi träffas på kafe?*

Затем более вежливый вариант:
* *Tack för förslaget. Idag är kallt, eftersom jag vill inte träffas i parken. Kan vi träffas på kafe efter jobbet?* ⚠️

Правка:
* *Tack för förslaget. Idag är det kallt, så jag vill inte träffas i parken. Kan vi träffas på kafe efter jobbet?*

Правило:
* *Idag är det kallt* — нужен формальный субъект *det*.
* Причина → результат: **..., så ...**
* *eftersom* = потому что; *så* = поэтому.

Мини-повтор:
1. *Idag är det kallt, så jag vill inte gå till parken.* ✅
2. *Idag arbetar jag eftersom jag kan inte komma.* ⚠️
   * Правка: *Idag jobbar jag, så jag kan inte komma.*
3. *Idag är bra vädret eftersom vi kan inte träffas i parken* ⚠️
   * Правка: *Idag är det bra väder, så vi kan träffas i parken.*

## Резюме

Закрепилось:
* *Tack för hjälpen / förslaget / förslagen* — контраст понятен после повтора.
* *gillar att + infinitiv*, *vill + infinitiv*, *kan + infinitiv*.
* *På lördag...*, *Efter det kan vi...* — V2 в простых цепочках держится.
* *en annan / ett annat* — контраст сдан чисто.
* Fritid-миницепочка уже близка к speaking-ответу уровня 3.

Осталось повторить:
* *så* vs *eftersom*.
* *Idag är det kallt / Idag är det bra väder*.
* *träffa någon* vs *träffas*.
* *kaffe* vs *kafe*.
